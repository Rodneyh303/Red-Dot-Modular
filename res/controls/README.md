# dot.modular control library

Generated by `panel_src/gen_controls.py`. **Do not hand-edit** — regenerate instead.

`RDM_<Palette>_<Size>_<Style>.svg` — 4 palettes x 6 sizes x 5 styles = 120.

## Palettes — chosen by measurement, not taste

| | vs dark panel `#232323` | vs light panel `#e6e6e6` | role |
|---|---|---|---|
| `OffWhite` | **12.8:1** | 1.0:1 | hero, dark theme |
| `Dark` | 1.2:1 | **10.9:1** | hero, light theme |
| `Grey` | **4.5:1** | **2.8:1** | secondary, **both** themes |
| `Cream` | 12.3:1 | 1.1:1 | previous hero; kept until the bindings move off it |

`Grey` reads as a control on either panel, so one grey serves both. The dark secondaries
bound today (BPM/LEN/OFFSET, MIX R/M) sit at **1.2:1** against the dark panel — not
subordinate, camouflaged.

`OffWhite` came from sampling the meloDICER photo: its big faces mean `#d8d1c2`, warmth
(R−B) **22** — against our Cream's **23**. Ours was never warmer than the reference; it is
flat. The photo reads white because of a specular highlight we cannot bake (see below), so
`OffWhite` cuts warmth to **8** instead of faking light.

## Sizes — footprints are load-bearing

| Size | viewBox | px | body R | arc gap |
|---|---|---|---|---|
| Large | 27.0 | 79.724 | 10.80 | 3.30 |
| Medium | 22.0 | 64.961 | 8.30 | 3.30 |
| Mid | 21.0 | 62.010 | 6.50 | 4.60 |
| Compact | 18.0 | 53.150 | 5.00 | 4.60 |
| Small | 16.0 | 47.240 | 4.00 | 4.60 |
| Trim | 11.0 | 32.480 | 3.60 | — |

`SvgKnob` sizes its box from the SVG, and `MonsoonWidget` computes the mod arc from that box
(`min(box)*radiusFrac + 0.6mm`). So the box pins the arc and **the body radius alone sets the
gap**. Changing either silently moves every arc.

## Styles

| | |
|---|---|
| `Cog` | hero / value. Round rim, raised 6-point cog inset from it, one concave arc between points. |
| `Bar` | **attenuverter** — cog body, pointer as a bar *through* centre. Says bipolar before the angle is read. |
| `Slot` | trim concept. Screwdriver slot; survives the downsample, and is already the bipolar bar. |
| `Quad` | trim concept. 4 flutes: ~2.7px per feature at actual size vs Cog's ~1.8. |
| `Dot` | trim concept. Red dot indicator — most downsample-robust; but ~38 of them may dilute the brand accent. |

## Constraints (why it looks the way it does)

- **Rack rotates the whole SVG.** Geometry is fine (a cog *should* turn). Radially symmetric
  shading is fine. **Directional light is not** — a baked highlight would spin with the knob,
  which is backwards. A fixed gloss must be drawn by the widget, outside the rotation.
- **nanosvg ignores `<filter>`** entirely — the old assets' `feDropShadow` never once rendered.
- **Rack's `svgDraw` keeps only a gradient's first and last stop**, so 3-stop bodies silently
  lost their middle. Everything here is solid fills.
- **Legibility floors.** A trim is ~10px across at zoom 1. The pointer is floored at 0.45mm
  (~1.3px) — it used to scale linearly with R and went **sub-pixel** on Small (0.9px), which is
  what BPM/LEN/OFFSET and MIX R/M use. Strokes scale at `0.028*R` rather than a fixed 0.30mm,
  which was 3x proportionally heavier on a trim than on a Large.

# dot.modular jack library

Generated by `panel_src/gen_jacks.py` (sibling of `gen_controls.py`). **Do not hand-edit** —
regenerate instead. Wrapped for use by `src/ui/GeneratedJack.hpp`.

`RDM_Jack<Palette>_<Size>.svg` — 4 palettes x 3 sizes = 12.

## Why

The stock Rack `PJ301M` jack is visually large on a dense panel. These jacks come in smaller
sizes, in the **same palette families as the knobs**, so a panel can shrink its jacks (knobs
unchanged) to free horizontal room — e.g. for the voice-LOR controls next to each lane
(`UNIFIED_ADDRESSING_SYSTEM.md`, voice-LOR gaps) without needing a subpanel.

## Sizes — footprints

| Size | viewBox (mm) | px | nut R (mm) | vs stock PJ301M |
|---|---|---|---|---|
| `Std`   | 8.40 | 24.80 | 3.65 | ≈ stock footprint (drop-in) |
| `Small` | 6.80 | 20.08 | 2.95 | ~19% narrower |
| `Tiny`  | 5.80 | 17.13 | 2.50 | ~31% narrower |

`SvgPort` sizes its box from the SVG `width/height` and connects cables at the box **centre** —
so every face is drawn around `(0,0)` with the bore at centre (load-bearing: an off-centre bore
would attach cables off the jack). Same `px`-width / `mm`-viewBox convention as the knobs.

## Palettes

Shared with the knobs (`Dark` / `OffWhite` / `Cream` / `Grey`) so jacks read as members of the
same instrument, not Rack defaults. A jack face uses: metal **nut** (rim), **sleeve insert**, dark
**bore**, outline **edge**. Palette dicts are duplicated in `gen_jacks.py` (kept independent, like
the repo's split) — **if the knob palettes change, re-sync these.**

## The widget — best of both worlds (`src/ui/GeneratedJack.hpp`)

`GeneratedJackT` inherits **`rack::app::SvgPort`** — the same base `PJ301MPort` uses — so **all
cable / drag / shadow / hover plumbing is Rack's, unchanged.** It only swaps the **graphic** via
`setSvg()`: *optionally replace, don't reimplement.* A use site can still use stock `PJ301MPort`
anywhere; these are a drop-in alternative where a smaller/custom jack is wanted.

- **Themed** — swaps the face for the panel (ThemedKnobT convention: light panel → Dark face,
  dark panel → OffWhite face). Set `lightTheme`.
- **Optional brand ring** — `brand = JackBrand::Red | Gold` paints a hairline NanoVG ring on top
  (one code path, both themes), like `GoldPolyPort`, over the generated face at the chosen size.

```cpp
auto* p = createInputCentered<redDot::Jack_Small>(pos, module, ID);
p->lightTheme = [module]{ Monsoon* m = redDot::lookupMonsoon(module); return m && m->lightTheme; };
addInput(p);
```

Aliases: `Jack_Std`, `Jack_Small`, `Jack_Tiny`.

## Constraints (same discipline as the knobs)

- **No `<filter>`, no multi-stop gradients** — nanosvg ignores filters; Rack's `svgDraw` keeps only
  a gradient's first+last stop. Depth is solid concentric fills (nut → insert → inner ring → bore).
- **Strokes scale with radius** (`0.055*R`, floored at 0.10mm) so a `Tiny` jack doesn't read as an
  outlined blob.
- **Bore centred at `(0,0)`** — the cable attach point must be the jack centre.
