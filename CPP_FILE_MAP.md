## Orientation

Red-Dot-Modular is a VCV Rack plugin built around **Monsoon**, a stochastic 16-voice sequencer driven by clock/gate/phase, with seven probability lanes (MEL/OCT/QMIX/REST/ACCENT/VAR/LEG) and dice-based pattern generation. Monsoon's `process()` is decomposed into a manager set (`src/dsp/managers/`) over the engine cores (`src/dsp/engines/`), with pure rack-free DSP cores in `src/dsp/`. The **Sands** family (Straits chain + East/Macro visuals) is the lane/DNA editor subsystem; the **Straits** chain spawns hidden lane and subgate panel models that dock onto it. Around the host sit the expander ring (Changi, Raffles, Junction, Causeway, Interchange, Shophouse, ChangeAlleyV2, Cantonment), the tuning family (Sikit → Colonnades/Duo → Shophouse Micro), and standalone modules (PhaseDistortion, Keppel, Lantern, Intertropical, DmcurveDevHost).

House rules visible throughout the tree: the de-param law (store-backed `StoreKnob`s instead of Rack params), strong index types (`VoiceSlot`, `LaneId`), single-writer store disciplines, block-consistent mutex-guarded snapshots, topology-epoch memoization instead of expander-chain walks, and bit-exactness gates in the test battery.

## 1. Plugin entry points

- `plugin.cpp` — Three-line repo-root stub: includes `rack.hpp` only; its comment claims the logic "moved to src/MeloDicer.cpp to resolve linker issues" (that file no longer exists) — the actual entry point is `src/plugin.cpp`. Registers/initialises nothing itself.
- `src/plugin.cpp` — The real plugin entry point: defines `pluginInstance` and `init(Plugin*)`, registering the **40 active models** (Monsoon, the expander ring, the Sands visuals/subpanels, the 5 hidden lane expanders + 8 hidden subgate panels spawned by StraitsBase, PhaseDistortion, the tuning family, Keppel, Lantern, Intertropical, the dev host) and warming the Phi/PhiInv LUTs on the load thread; deprecated models are commented out.

## 3. DSP cores — `src/dsp/`

### 3.1 Rack-free DSP headers (`src/dsp/*.hpp`)

- `src/dsp/CAPendingOrder.hpp` — Rack-free helper giving chronological pending-transform order for armed verb rows: stable insertion sort by monotonic arm-stamp, ties breaking by row index (the existing verb-major order). Reused as-is by CantonmentPending per the build plan.
- `src/dsp/CATrajectoryBuffer.hpp` — True-reverse trajectory-replay engine for Change Alley: per-stream (rhythm/melody/q-mix) rings of committed 16-pin states pushed post-commit; stepBack() restores the previous state, stops at buffer end, serialises a bounded version-guarded tail. Composed by MonsoonChangeAlleyV2.
- `src/dsp/CantonmentGraph.hpp` — Cantonment's articulation-containment state: a 16-voice multi-parent acyclic DAG as uint16 parents bitmasks (containment = intersection of parents); cycle rejection via ancestor wavefront and Kahn peel. Pure/rack-free; consumed by CantonmentTransforms/Pending/ModuleCore.
- `src/dsp/CantonmentModuleCore.hpp` — Rack-free module-state core of MonsoonCantonment: one unit holding the containment DAG, pending verb rows, EXPAND trajectory, pin-edit path, host-driven boundary apply, and an SPSC undo-snapshot ring drained by the widget; the Rack module adds only SDK surface.
- `src/dsp/CantonmentPending.hpp` — Phrase-boundary pending machinery for containment verbs: seven verb rows with latch/stamp/order reusing CAPendingOrder, dispatch onto pure verbs, the RANDOM row's Philox stream, the CantonmentTrajectory EXPAND ring, and true-reverse request queue; composed by CantonmentModuleCore.
- `src/dsp/CantonmentTransforms.hpp` — Pure DAG-closed gesture verbs over CantonmentGraph (rotate/reflect roles, invert, collapse/collapseAll/onto, reduceTransitive, seedForest, scatterEdges), each carrying its acyclicity-closure argument; active-pool discipline preserves above-pool rows; draws through PhiloxRng.
- `src/dsp/ChangeAlleyTransforms.hpp` — Change Alley's four restructure verbs over the 16-entry src[] table (domain/codomain collapse, rotateValues, reflect, scatter), tiling the active pool by blocks; scatter draws via a domain-separated Philox counter stream. Consumed by MonsoonChangeAlleyV2.
- `src/dsp/Distribution.hpp` — The distribution layer's probability core: abstract cdf/pdf/invCDF interface with tunable parametric types (Triangular, Power, Möbius, LogitNormal, Kumaraswamy, TruncatedNormal) and drawn Pchip, all closed-form-inverse, plus .dmcurve JSON serialization; wraps/copies GaussianCopula primitives.
- `src/dsp/GaussianCopula.hpp` — Shared Gaussian-copula primitives: exact Phi/phi, Acklam+Halley PhiInv, hot-path 4096-entry PhiLUT/PhiFast, and normal-space combine/mix2 keeping marginals exactly uniform (correlation = weight dot product). Used by slew, spread's mix2, and the Distribution layer.
- `src/dsp/LaneMapping.hpp` — Single source of truth for Sands lane orderings (editor lanes, engine strands, param/poly banks), identity-unified with the q-mix strand inserted at index 2; EngineStrand enum, lorStoreBank, and static_assert guards. Consumed by SandsGrid, East, Macro, expanders.
- `src/dsp/MacroTapBank.hpp` — Pure store contract for per-voice macro PRE/POST send-taps: 224 floats (16 voice-slots × 7 lanes × 2 kinds) with a documented index stride and JSON serialize/parse defaulting to POST 1.0; persisted via MonsoonPersistenceManager.
- `src/dsp/MonotoneCurve.hpp` — The .dmcurve editor's drawn distribution: a monotone non-decreasing CDF on [0,1] with pinned endpoints, evaluated by Fritsch–Carlson PCHIP; inverse via diagonal-reflection seed plus safeguarded Newton; jansson serialization. Wrapped by PchipDistribution/WarpF curve pools.
- `src/dsp/MovingAverageCopula.hpp` — Slew as a moving-average Gaussian copula: 64-tap geometric, L2-normalised weights over PhiInv'd draws combined in normal space then Phi — exactly uniform, reversible (r enters only at readout); r==0 bit-identical passthrough; consumed by PatternEngine's slew/scrub paths.
- `src/dsp/MpeMath.hpp` — Pure CV→MPE conversion math for Keppel's CV→MPE-out utility: nearest-12-TET note + centred 14-bit bend split (0V=C4), held-note bend tracking, round-trip reconstruction, X/Y/Z expression mappers and two-layer sumAroundRest; shared verbatim by tests and module.
- `src/dsp/NoteValues.hpp` — Single source of truth for the 13-entry note-length dial (dotted build): NOTE_VALUES in strict duration order, DIAL_ORDER display permutation, legacy-index remap for old patches, and the noteShorterOf fraction authority. Consumed by SequencerEngine, GateState, configurator/widget/persistence.
- `src/dsp/PhaseDistCore.hpp` — Standalone phase-distortion module's rack-free signal core: eight PhaseDistChannel one-sample-hop paths (out = transform(in(n−1))), identity sets passing raw voltage, normalisation via PhaseEngine::normPhase; PhaseDistBlockReader snapshots all eight sets once per control block.
- `src/dsp/PhaseDistCellHold.hpp` — dotModular::PhaseDistCellHold, the ENGINE-side PPQN-cell hold for the phase-distortion transform (CC_FIX_PHASE_DISTORT_AT_PPQN): the transform evaluated once per PPQN cell of the tier's input — transport via the plain probe's llround on the span grid (ring-wrapped), subphase via the fine term's floor on the region-relative grid — fired at the cell's own grid point (bit-identical), held between cells, reset on the raw path; Monsoon's two tier sites consume it, the display path never does.

### 3.2 Engine cores (`src/dsp/engines/`)

- `src/dsp/engines/ClockEngine.hpp` — Declares ClockEngine (plus local clkClamp to avoid a MeloDicer.hpp circular include): clkTrig SchmittTrigger, internal/external accumulators, ppqnCount/sixteenthCount grid counters, and the output contract pulseEdge/sixteenthEdge/quarterEdge + bpm + pulsesPer16th(). - `src/dsp/engines/ClockEngine.cpp` — Implements the unified PPQN pulse-grid clock: internal mode subdivides each 1/16 into pulsesPer16th (ppqn/4) pulses; external mode treats each SchmittTrigger-accepted CLK pulse as one grid pulse (assumed at ppqn PPQN) and derives bpm by measuring the 1/16 interval. Sets pulseEdge/sixteenthEdge/quarterEdge consumed by the execute path.
- `src/dsp/engines/PatternEngine.hpp` — Stochastic pattern generation: owns both Philox RNG states, generated pattern arrays (melodySemitone, melodyPitchV), and seed management; defines kMaxPatternSteps/kStepStorage/kPatternLengthCap and the uint64 length-masked mask plane (STEPS_32); also the display selection pair — displayedVoice_ (East's tabs) and sendVoice_ (the Macro strip's sends addressing, CC_FIX_SEND_VOICE_FROM_MACRO), both minted VoiceSlot. - `src/dsp/engines/PatternEngine.cpp` — Implements PatternEngine's stochastic generation: file-local OUBridgeCoeffs computes unified 2×2 OU-bridge conditioning (monotone/oscillatory kernels, ξ injected via Philox atUniform), promoteRemappedDraws_ mints VoiceSlots for poly lane writes, reset() seeds the Philox draw engines and default pattern rows. Includes VoiceResolver (the mint authority), WarpF, SpreadInterp.
- `src/dsp/engines/PhaseEngine.hpp` — Header-only Mode E clock source: an external phase-ramp CV drives playhead position instead of a clock generating it. Maps phase 0→1 to the active patternLength span in PPQN pulses, emitting ClockEngine's edge contract plus reverse/jumped/jumpSixteenths (jumps replay 1/16 steps, bounded to the phrase); processTiers() (Stage 2) composes transport+subphase via the quotient/remainder formula, with semantic direction as dirT·dirS composed by Monsoon. CC_FIX_PHASE_RUN_AT_PPQN: a cheap per-sample path (trackers + the prevContPhase accumulator, a running sum across skipped samples) feeds a pulse-change gate — the tail (velocity, jump detection, the walk) runs only when the quantised target (llround(prevContPhase·PPB) / tierPulseFor) moved off prevPulse, exposed as pulseChanged for Monsoon's snap/drift gating.
- `src/dsp/engines/RhythmDecisionCore.hpp` — The rack-free Rhythm Decision Manager (RDM), composed by SequencerEngine: MonoDecision vocabulary, ParentView container reads, the five C1–C5 predicates (onset permission, rest close, length ceiling via noteShorterOf, hold follow, envelope AND), and the RhythmDecision verdict tuple. Materializes the 16-voice containment forest (Kahn topological order) from staged containmentParents; computes permissions only, owns no state.
- `src/dsp/engines/SequencerEngine.hpp` — The step/playback orchestrator: composes PatternEngine (pe), mono GateState gs/gsStep, a VoiceBank of 16 PolyVoice (own GateState, rest/accent/legato probs, subgate thresholds, bipolar variationProb), RhythmDecisionCore rdm, position-holder lane machinery, and the debug-only WriteLedger/StrandWriter single-writer guards. Declares executeStep/executeModeA/B/BSubdivided/executePolyVoices; Monsoon and expander managers are the callers.
- `src/dsp/engines/SequencerEngine.cpp` — Implements the step engine: laneTickFor's walk shapes (Forward/Reverse/Pendulum/PingPong, local-mod continuity replacing the deleted DNA_LCM global counter), driverTickAt/driverTickBefore unified-LOR window maps, reset(), and the execute path — executeStep, executeModeA/B/BSubdivided, monoParentView, executePolyVoice(s).
